Laporan Teknis Redesign & Sistem Tema

Dokumen ini merangkum seluruh perombakan antarmuka (UI) pada halaman Login, Explore, dan Bottom Navigation Bar sesuai rancangan mockup desain terbaru. Perubahan ini diimplementasikan secara modular dengan menjaga orisinalitas proses bisnis (CRUD) database dan API yang telah Anda bangun sebelumnya.

Ringkasan Modul Perubahan

T
Sistem Tema Global

Penyediaan pengendali tema terpusat (ValueNotifier) yang memungkinkan perpindahan mode gelap dan mode terang (Dark/Light Mode) secara real-time pada seluruh halaman.

L
Login Page Redesign

Modernisasi pemilih role (pembeli/pedagang), form input, warna tombol masuk, dan transisi modal card dengan tetap mempertahankan CRUD login SQLite/SharedPrefs.

E
Explore Page Redesign

Mengubah layout searchbar dan filter chips agar melayang di atas peta, membuat penunjuk lokasi speech-bubble kustom, serta memperbarui sliding pedagang aktif.

N
Bottom Nav Capsule

Mengganti BottomNavigationBar default dengan kontainer kustom berdesain kapsul melengkung premium, berlatar belakang adaptif, dan aktif menonjolkan teks.

Detail Teknis File yang Diubah

Tema Terpusat lib/main.dart

  • ValueNotifier & ValueListenableBuilder: Menginisialisasi variabel status global isDarkModeNotifier = ValueNotifier<bool>(false).
  • MaterialApp Rebuild: Membungkus MaterialApp dengan builder yang mendengarkan perubahan status notifier tersebut, sehingga dapat menyetel kecerahan sistem (brightness) dan warna latar belakang scaffold secara real-time tanpa memerlukan framework state management berat.

Struktur Teknis Notifier

final ValueNotifier<bool> isDarkModeNotifier = ValueNotifier<bool>(false);

// di dalam MyApp.build
return ValueListenableBuilder<bool>(
  valueListenable: isDarkModeNotifier,
  builder: (context, isDark, child) {
    return MaterialApp(
      theme: ThemeData(
        brightness: isDark ? Brightness.dark : Brightness.light,
        scaffoldBackgroundColor: isDark ? const Color(0xFF1C1C1E) : Colors.white,
      ),
      home: const SplashScreen(),
    );
  }
);

Halaman Login Baru & CRUD Aman lib/features/auth/presentation/pages/login_screen.dart CRUD Aman

  • Pemilih Pilihan (Role Toggle): Mengubah area pemilih peran "Pembeli" atau "Pedagang" menjadi pill slider rounded dengan tinggi 44 dan padding 4. Saat dipilih, warna berpindah secara halus menggunakan AnimatedContainer.
  • Text Field Moderen: Bidang input teks (Nomor Telepon/Email & Kata Sandi) kini memiliki latar belakang lebih pekat (Gelap: #1C1C1E, Terang: #F1F5F9) dengan fokus border oranye #F5A623.
  • Kejernihan Ikon Vektor (SVG): Mengganti penanda logo media sosial statis (Google & Facebook) dengan markup SVG murni melalui SvgPicture.string. Google kini menggunakan warna orisinal brand (Multi-colored G), sedangkan Facebook menggunakan ikon 'f' putih pada latar adaptif.
  • Tombol Masuk: Memperbaiki kontras teks tombol "Masuk" dengan menyetel warna teks menjadi gelap (#1C1C1E) di atas warna oranye utama #F5A623 sesuai mockup.
  • Keamanan CRUD (SANGAT PENTING): Fungsi pemicu login _handleLogin() dan penyimpanan sesi AuthService.saveUserSession(result) sama sekali tidak disentuh untuk menjaga kelancaran proses otentikasi database lokal SQLite.

Optimasi Layout Peta & Detail lib/features/auth/presentation/pages/explore_screen.dart Struktur Baru

  • Penumpukan Objek (Stacking): Agar sesuai mockup di mana garis-garis grid peta mengalir di bawah bilah pencarian dan filter chips, kami mengeluarkan searchbar dan chips dari Column luar. Komponen tersebut diletakkan di dalam Stack milik _buildMapArea, ditata menggunakan widget Positioned di posisi teratas.
  • Searchbar Melayang: Didesain ulang dengan latar putih (terang) / abu pekat (gelap), bergaris oranye tegas dengan ketebalan 1.5, serta dilengkapi efek bayangan (shadow) halus untuk memberikan kesan melayang di atas peta.
  • Tombol Pengalih Tema di AppBar: Menyisipkan IconButton ganti tema dengan ikon Matahari/Bulan dinamis pada deretan kanan AppBar untuk mengubah status isDarkModeNotifier secara instan.
  • Speech Bubble Markers: Mengubah pin penanda pedagang yang sebelumnya standar menjadi bentuk balon dialog (Speech Bubble). Dibuat menggunakan paduan kontainer bersudut tumpul (capsule) dan ikon segitiga Icons.arrow_drop_down_rounded di bagian bawah tengah kontainer. Penanda "Nasi Uduk" diberi warna abu-abu (tidak aktif), sementara yang lain diberi warna oranye (aktif).
  • Bilah Geser Pedagang (Sliding Panel): Latar belakang panel diubah menjadi putih bersih (Light Mode) dan abu gelap (Dark Mode). Bagian pegangan atas (drag handle) diberi warna abu terang #E2E8F0.
  • Kartu Pedagang Berindikator Aktif: Latar belakang kartu pedagang dibuat adaptif. Di bagian foto profil (avatar), dipasangi badge lingkaran kecil berwarna hijau terang (#4CD964) yang diposisikan di sudut kanan bawah menggunakan Stack untuk menunjukkan status online.

Detail Rendering Tab Aktif Kapsul

Widget _buildNavItem(int index, String label, IconData activeIcon, IconData inactiveIcon, bool isDark) {
  final bool isSelected = _currentIndex == index;
  return Container(
    padding: const EdgeInsets.symmetric(horizontal: 14, vertical: 8),
    decoration: BoxDecoration(
      color: isSelected ? const Color(0xFFF5A623) : Colors.transparent,
      borderRadius: BorderRadius.circular(12),
    ),
    child: Column(
      children: [
        Icon(isSelected ? activeIcon : inactiveIcon, color: isSelected ? Colors.white : inactiveColor),
        Text(label, style: TextStyle(color: isSelected ? Colors.white : inactiveColor)),
      ],
    ),
  );
}
